# La idea es generar una api REST con php que me permita generar un CRUD dinamico para cualquier tipo de tabla en la base de datos.
# El sistema realizar es una api REST con php y mysql.
# Reglas

- la tablas se nombre en plural y nombre de la tabla se nombra en singular del nombre de la tabla
ejemplo: usuarios -> id_usuario
- la primra columna es id y las dos ultimas son date_create y date_update
